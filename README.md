# 🚀 Capestone Project Navigate Labs

A simple and interactive web application built using **Streamlit**, designed to provide a clean and smooth navigation experience.

🔗 **Live App:** https://capestone-project-nav.streamlit.app/

---

## 🌟 Features

- ⚡ Lightweight and fast  
- 🎯 Simple and user-friendly UI  
- 🧩 Built using a single Python file  
- 🌐 Deployed using Streamlit Cloud  

---

## 🛠️ Tech Stack

- Python  
- Streamlit  

---

## 📂 Project Structure

```
Capestone-Project/
└── streamlit_app.py
```
